# Layarku Android

Kotlin + Jetpack Compose client (package `com.hanan.layarku`).

> Placeholder. The Android project is created in **phase 3** (see [SPEC.md](../SPEC.md) section 13).

Planned stack: Compose + Material 3, MVVM (`ui` / `domain` / `data`), Hilt + KSP, Retrofit + kotlinx.serialization, Room, DataStore, Coil, FCM, CameraX + ML Kit.

The emulator reaches the local backend at `http://10.0.2.2:8000`.
